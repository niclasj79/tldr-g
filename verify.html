Verify a TLDR-G receipt

Checks a signed artifact offline, in this page. Nothing is uploaded — there is no server to upload to. Works with no internet connection and no software installed.

What a valid verdict proves. The payload is byte-for-byte what the holder of this key_id signed. It does not by itself prove who that holder is — to establish identity, match the key_id and public_key shown above against the signer's published did:web document. It also makes no claim about whether the content is true: it proves the record is unaltered, not that the world agrees with it.
Ed25519 + SHA-256, verified locally via the Web Crypto API with a pure-JavaScript fallback. This file is self-contained and offline — save it and it keeps working. Same result as the tp-vrg-verify CLI.
